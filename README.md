# 财务建模实操课

一个教你**一步一步做财务建模**的中文学习网站：从下载数据、清洗数据开始，从零搭建三表模型，再根据问题选择并搭建 DCF、可比公司、LBO 等分析方法。每一步都写清楚要注意什么、可能出现什么问题、该怎么思考。

配套一个虚构公司"青禾饮品"的完整练习：脏数据 CSV、Excel 练习模板、参考答案，以及每一步的检查点数字。

## 怎么打开

不需要安装任何东西：

- **本地**：双击 `index.html`，用浏览器打开即可（离线可用，只有字体需要联网，没网时会用系统字体）。
- **GitHub Pages**：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支选这个分支、目录选 `/ (root)`，保存后几分钟就能通过网址访问。
- 在手机上也能看，学习进度保存在当前浏览器里。

## 内容结构

| 章节 | 内容 |
| --- | --- |

| 4 搭建三表模型 | 骨架、假设与情景、收入、成本、营运资本、固定资产、借款与循环引用、三表配平、排错、检查 |
| 5 分析方法 | 方法选择、DCF、WACC、可比公司、先例交易、DDM / P/B–ROE、LBO、敏感性与情景、足球场图 |
| 6 实战案例 | 青禾饮品从原始数据到估值，10 步检查点 + 完整参考答案逐行对照 |
| 互动工具 | 方法选择器、DCF 计算器、三表联动模拟器、配平排错助手、LBO 计算器 |
| 速查手册 | 常用函数、术语中英对照、交付前总检查清单 |

## 练习文件（`practice/`）

| 文件 | 用途 |
| --- | --- |
| `青禾饮品_原始数据.csv` | 模拟从网站下载的报表：单位是元、数字是带逗号的文本、括号负数、年份倒序、科目带空格 |
| `青禾饮品_练习模板.xlsx` | 原始数据、映射表、历史数据、假设已做好；预测期和估值的黄色单元格留给你填 |
| `青禾饮品_参考答案.xlsx` | 完整模型，全部是公式；"假设"页 C2 可切换基准 / 乐观 / 悲观情景 |

公司、数据、股价和市场参数都是为教学虚构的，不构成投资建议。

## 修改案例数据

案例的所有数字都来自 `scripts/build_case.py`（唯一数据源）。改了假设后运行：

```bash
python3 scripts/build_case.py
```

会重新生成 `practice/` 下的三个文件和网站使用的 `js/case-data.js`，网站和 Excel 始终保持一致。需要 Python 3 和 `openpyxl`。

openpyxl 写出的公式没有缓存结果，用 Excel 打开会自动计算；但手机或微信里预览时会显示空白。发布前建议用 Excel 或 LibreOffice 打开两个 xlsx 文件、重新计算后保存一次。

## 代码结构

```
index.html            页面骨架
css/style.css         样式（浅色 / 深色主题）
js/core.js            命名空间、章节定义、内容辅助函数（迷你工作表、提示框、清单…）
js/content/*.js       各章课程内容
js/tools/*.js         互动工具和案例组件
js/app.js             导航、路由、进度、搜索、首页
js/case-data.js       案例数据（自动生成）
scripts/build_case.py 生成案例数据和 Excel 练习文件
practice/             练习文件
```

纯静态 HTML + 原生 JavaScript，没有构建步骤和依赖。新增一节课：在对应的 `js/content/*.js` 里调用 `FM.add({ id, ch, num, title, lede, time, level, body })` 即可。
