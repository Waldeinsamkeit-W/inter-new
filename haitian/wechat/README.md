# 公众号版

把分析底稿改写成适合公众号的版本：口语化正文 + 16 张手机竖屏配图。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 图文版正文和预览页。深色头图、小节编号与导语、结论/数据/信号卡片、金句、划重点都是行内样式的真文字，只有图表是图片。浏览器打开即可看到效果；点“复制正文”可直接粘贴进公众号编辑器（图片位置显示为虚线占位框） |
| `images/` | 配图。`00_封面_2.35比1.png`（1800×766，头条封面）、`00_封面_1比1.png`（1080×1080，方形裁切参考），`01`–`14` 为正文配图，宽 1080 像素 |
| `build_images.py` | 生成全部配图：卡片先写成 HTML（图表由 matplotlib 输出 SVG），再截图 |
| `shoot.cjs` | 截图脚本（Node + Playwright） |
| `longimage/` | 整篇长图：`海天七年财报拆解_长图.jpg`（1080×34035，约 3,676 万像素，适合存档或发其他平台），以及按小节切开的 8 段（每段不超过 600 万像素，可直接上传公众号正文） |
| `build_long_image.py` | 生成长图：正文从 `index.html` 读取，图表复用配图组件，排版后分段截图再拼接 |
| `shoot_long.cjs` | 长图分段截图脚本 |

## 发布步骤

1. 在浏览器打开 `index.html`，点“复制标题”“复制摘要”“复制正文”，分别粘贴到公众号后台。
2. 正文里每个虚线框写着该放哪张图，按文件名上传 `images/` 里的图片，再删掉虚线框。
3. 封面上传 `00_封面_2.35比1.png`。

## 重新生成配图和长图

```bash
python wechat/build_images.py
```

```bash
python wechat/build_long_image.py
```

需要 `node` 和 `playwright`；字体用 Noto Sans SC（中文）和 Barlow Condensed（数字），未安装时浏览器会退回系统字体。图里的数字都由 `analysis.py` 现算，改了 `data/` 下的数据后重跑即可。

注意：`index.html` 的正文是手写的，里面的数字是文字。改了数据后，正文中的数字需要手动同步。

## 公众号为什么传不了整张长图

公众号正文的单张图片要求宽 × 高不超过 600 万像素（文件大小另有 5–10 MB 的限制）。整张长图约 3,676 万像素，所以要用分段版：按顺序把 `第1段` 到 `第8段` 依次插入正文。切分点都在小节或图表开头的留白处，图片之间的间隙看起来就是段落间距。

## 改正文

直接改 `index.html` 的 `<article>`。每个块占一行，并带 `data-role` 标记：`hero` 头图、`lead` 开头段、`p` 正文、`sec` 小节标题（`data-no`、`data-kicker`）、`fig` 图片（`data-file`）、`key` 划重点、`quote` 金句、`native` 文字卡片、`small` 注释、`foot` 数据说明。长图脚本按这些标记解析，新增内容时保持“一块一行、带标记”。
