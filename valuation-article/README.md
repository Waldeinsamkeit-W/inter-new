# 公众号图文：估值模型全攻略

一篇面向公众号读者的估值科普长文，约 1.4 万字，配 13 张图和 2 张封面。内容覆盖不同估值模型的特点和适用场景、正确使用方法、实际工作中的操作流程，以及多种方法结论不一致时如何处理。全文用一个虚构公司「小鲜饮品」贯穿始终，所有案例数字都由 `src/model.py` 计算得出，前后一致、可以复核。

## 文件

| 文件 | 用途 |
|---|---|
| `wechat.html` | **发布用**。浏览器打开后点“复制正文”，粘贴到公众号编辑器即可。图片已内嵌，单个文件就能用 |
| `article.md` | 正文 Markdown 源文件，修改内容改这里。也可以粘贴到 mdnice 等 Markdown 排版工具 |
| `images/` | 全部配图（1680px 宽 PNG）和封面 |
| `src/package_images.py` | 把配图按中文名重命名、附插图位置说明，打包成一个文件夹和 zip |
| `src/` | 生成配图和排版文件的脚本 |

## 发布步骤

1. 用电脑浏览器打开 `wechat.html`。
2. 公众号后台新建图文，填写标题（见下方备选）。
3. 点页面上的“复制正文”，在编辑器正文区粘贴。字号、颜色、表格和公式框都会保留。
4. 逐张检查配图。如果某张图粘贴后不显示或保存时报错，删掉它，在原位置上传 `images/` 里同编号的图片。
5. 封面：头图用 `images/cover.png`（2.35:1），分享卡片用 `images/cover-square.png`（1:1）。
6. 摘要用页面上的“复制摘要”，或直接复制下面的文字。
7. 先发送到手机预览，通读一遍再群发。

## 修改与重新生成

改了文字，只需重新生成 `wechat.html`；改了案例假设，就把三步都跑一遍：

```bash
cd valuation-article/src && npm install
```

```bash
python3 model.py
```

```bash
node figures.cjs
```

```bash
node build.cjs
```

需要按中文名打包配图时：

```bash
python3 package_images.py ~/Desktop
```

`figures.cjs` 需要本机有 Playwright 和 Chromium。`model.py` 只用 Python 标准库。修改假设后，记得把正文里引用的数字（如 105.8 亿元、每股 10.58 元、92～125 亿元等）同步更新，`model.py` 的输出里都能找到。

## 说明

- 「小鲜饮品」及 A～E 可比公司均为虚构，数据仅用于教学演示，不构成投资建议。
- 无风险利率、市场风险溢价、控制权溢价、流动性折扣、集团折价、新药获批概率等参数，文中给出的是常见的经验区间。实际使用时请以估值基准日的市场数据和具体情况为准。
